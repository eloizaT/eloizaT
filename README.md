## My Engineering Philosophy

Good automation isn't just a script that saves a few commands.

I aim to build tools that are:

**Reusable** — useful beyond a single task or environment
**Testable** — behavior can be verified automatically
**Maintainable** — structured so the tool can evolve
**Observable** — failures provide useful information
**Documented** — another engineer can understand and use it
**Practical** — solves a real engineering problem
